# questlog-kr-rules

Questlog 한섭 패처(퀘스트로그한섭패치 rev7.8 이상)가 읽는 패치 규칙 저장소입니다.

- 패처는 실행할 때 `rules/manifest.json`을 확인해서, 패처에 들어 있는 규칙보다 새 버전이면 `rules/` 안의 규칙을 받아 씁니다.
- 받은 파일은 manifest에 적힌 SHA256과 같아야만 사용합니다. 하나라도 다르거나 인터넷이 안 되면 패처에 들어 있는 규칙으로 진행합니다.
- 규칙 파일은 Questlog에 들어가는 코드를 담고 있습니다. 이 저장소에는 관리자 외에 쓰기 권한을 주지 마세요.
